ov.capture.probes.console

Console probe: console messages, page errors, and unhandled rejections.

Captured from Playwright console/pageerror events. Each entry carries the step it occurred in so the UX engine can attribute console-error-on-step (§5.1 heuristic) and the robustness analysis can corroborate broken states.
