ov.__main__

Command-line interface – argh dispatch over the same facade functions (§4).

This is the deterministic, scriptable face of the library (dispatch-to-interface): ov observe <url>, ov analyze <run_id>, ov report <run_id>, ov synopsis <dir>, ov overview <url>, and ov check (requirements). Each command calls the very functions a skill or a normal caller would call.
