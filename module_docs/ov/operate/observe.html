ov.operate.observe

observe(page, strategy) -> Observation – the pure-read primitive.

A thin, timed wrapper over the perception strategies. It performs no action and mutates no state; it is the “perceive” in perceive->decide->act->record.

ov.operate.observe.observe(page: Any, strategy: str = 'ax_snapshot') → Observation[source]

Perceive the current page state with strategy and return an Observation.
