ov.operate.act

act(page, action) -> ActionResult – execute one action, return a fresh read.

Every action returns success/error plus a fresh Observation, so the policy layer can decide the next step without a separate observe call. Actions that touch an element target it by the stable data-ov-ref stamped during perception; unknown refs and Playwright errors are caught and surfaced as a clean ActionResult error (e.g. a stale ref the host should re-observe to fix).

ov.operate.act.act(page: Any, action: Action, *, perception: str = 'ax_snapshot', polite_rate_s: float = 0.0) → ActionResult[source]

Execute action against page and return the result + a fresh Observation.

On failure, ok=False and error carries the message; a fresh Observation is still attached so the host can recover (re-observe, scroll, disambiguate).
