ov.operate

The operate layer – deterministic, LLM-free tool primitives (the “hands”).

This is the package-owned tool plane from §2.3. It composes as journal(progress(act(observe()))) and contains no model and no policy: it perceives affordances, executes actions, records the journey, and reports loop/no-progress facts. The decision of what to do next and when to stop belongs to the policy plane – the host (Claude Code) via the ov-operate skill, or, later, an in-package agent.

Primitives (each is individually callable and testable):

  • observe() – observe(page, strategy) -> Observation

  • act() – act(page, action) -> ActionResult (returns a fresh Observation)

  • journal() – append a structured per-step record

  • progress() – loop/no-progress facts (never decides to stop)

  • perception strategies – PERCEPTION_REGISTRY

ov.operate.act(page: Any, action: Action, *, perception: str = 'ax_snapshot', polite_rate_s: float = 0.0) → ActionResult[source]

Execute action against page and return the result + a fresh Observation.

On failure, ok=False and error carries the message; a fresh Observation is still attached so the host can recover (re-observe, scroll, disambiguate).

ov.operate.journal(run: CaptureRun, step: JourneyStep) → JourneyStep[source]

Append step to run.steps and return it.

ov.operate.make_step(*, intent: str, action: Action | None = None, pre_observation: Observation | None = None, result: ActionResult | None = None, artifact_ids: list[str] | None = None, network_delta: int = 0, console_delta: int = 0, note: str | None = None) → JourneyStep[source]

Build a JourneyStep from an action’s before/after observations.

outcome is derived: error on a failed action, noop when the post-observation hash equals the pre-observation hash (nothing changed), else ok.

ov.operate.observe(page: Any, strategy: str = 'ax_snapshot') → Observation[source]

Perceive the current page state with strategy and return an Observation.

>>> from ov.operate.perception import PERCEPTION_REGISTRY
>>> "ax_snapshot" in PERCEPTION_REGISTRY
True
ov.operate.perceive(page: Any, strategy: str = 'ax_snapshot') → Observation[source]

Dispatch to the named perception strategy (defaults to ax_snapshot).

Raises KeyError with the known strategies when strategy is unknown – an informative error per the project’s principles.

ov.operate.progress(history: list[JourneyStep], *, no_progress_steps: int = 3) → ProgressSignal[source]

Compute loop/no-progress facts from the journey history so far.

>>> from ov.base import JourneyStep, Action
>>> s = JourneyStep(action=Action(type='click', ref='e1'), post_obs_hash='h')
>>> sig = progress([s, s.model_copy(), s.model_copy()], no_progress_steps=3)
>>> sig.no_new_signal_steps >= 3 and sig.loop_suspected
True
