ov.analysis.arch.rendering

Rendering-model classifier: CSR vs SSR/SSG via raw-HTML-vs-rendered-DOM diff (D2).

The deterministic test compares the server-sent HTML (the captured document response body, pre-JS) against the rendered DOM (post-JS). A large divergence => CSR (server sends a shell, JS builds the page); near-identity => SSR/SSG. This is computed entirely from captured artifacts – no re-fetch – so it stays hermetic. State-injection globals (__NEXT_DATA__/__NUXT__/__remixContext) corroborate SSR/SSG. SSG vs SSR needs multiple requests and is left as a refinement.
