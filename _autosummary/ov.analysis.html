ov.analysis#

Analysis layer: deterministic analyzers over captured artifacts (Phases 2-3).

Analyzers are registered plugins (ANALYZER_REGISTRY) that read a CaptureRun plus its store and emit :class:`~ov.base.Finding`s / :class:`~ov.base.Endpoint`s / facts – all model-free and fully testable on synthetic artifacts. The host (or, later, an in-package agent) adds narrative judgment on top of these via the evidence bundle.

Each analyzer is registered with a lens ("ux" or "arch") so ov.analyze(run, lenses=...) can select which to run; requires/produces order them. The builtins are eagerly imported on first import of this package so the registry is never half-populated (same robustness rule as the probes).

(The package is named analysis rather than analyze so it cannot shadow the ov.analyze facade function; see ov/__init__.py.)
